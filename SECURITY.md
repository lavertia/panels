# Security policy

Lavertia is under active pre-release development. No version is currently declared production-ready.

## Privately reporting vulnerabilities

Do **not** publish exploit details, tokens, credentials, or other sensitive information in GitHub Issues, Discussions, or pull requests. Use GitHub's **Report a vulnerability** / private vulnerability reporting flow for this repository if enabled. Otherwise, contact a repository maintainer through an established private channel and request secure disclosure instructions.

Please include the affected commit or version, reproduction steps, impact and proposed mitigation where possible. Do not include working production secrets or personal data.

Security fixes are prioritized according to exploitability and impact; no response or patch deadline is guaranteed. Maintainers will coordinate responsible disclosure when a valid report is confirmed.

## Supported versions

This repository is an experimental v0.x preview. Treat it as unsupported for production use until a version support policy is announced.
